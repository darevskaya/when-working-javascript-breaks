COOP: popup login with BroadcastChannel

Each link opens one mode of this demo in a new tab.

The same modes. The login returns through a callback page on the app origin, not through window.opener.

  • No COOP: login works Neither page sends COOP.
  • COOP on the app page: login works The app page sends Cross-Origin-Opener-Policy: same-origin
  • COOP on the login page: login works The Orbit ID login sends Cross-Origin-Opener-Policy: same-origin
