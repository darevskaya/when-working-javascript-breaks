Restrict the architecture with ESLint

Two lint rules keep every API call inside one contract: api-client.js is the only file that calls fetch, and config.js is the only file that names an origin. The server builds connect-src from the same config.js.

  • The policy comes from config.js: both calls load connect-src 'self' http://127.0.0.1:4308
  • A customer who never listed the API origin: both calls fail connect-src 'self'
