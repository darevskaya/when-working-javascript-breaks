Playwright under security policies

The same page, the same script, two sets of headers. Open a link to see the page, or run the Playwright projects to see the same difference in a test report.

  • Worker allowed: the worker replies worker-src 'self' blob:
  • Worker blocked: the browser refuses the worker script-src 'self'; frame-ancestors 'none'

The two Playwright projects

  • npm run test:permissive: Playwright puts a permissive policy on the response, and the test passes
  • npm run test:strict: Playwright puts a strict policy on the same response: the worker fails on purpose, and the iframe fails as the test expects
