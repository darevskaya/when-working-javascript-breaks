Playwright under security policies

The server sends no Content Security Policy. Each Playwright project adds one to the response it is testing.

  • Worker page: the page starts a Blob worker test/worker.spec.js
  • Iframe page: the page embeds another page test/iframe.spec.js

The two Playwright projects

  • npm run test:permissive: allows Blob workers and iframe embedding, so both tests pass
  • npm run test:strict: blocks the Blob worker, so that test fails on purpose. It also blocks iframe embedding; that expected failure is reported as passed by Playwright.
