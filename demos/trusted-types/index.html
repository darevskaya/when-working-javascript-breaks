Trusted Types: innerHTML

Every route serves the same page and the same script. The route picks the widget style, and the header the server sends.

  • string, no header: the shop name becomes a tag no Trusted Types header
  • string, header on: the browser refuses the write require-trusted-types-for 'script'; trusted-types 'none'
  • escapeHtml, header on: the browser refuses it too require-trusted-types-for 'script'; trusted-types 'none'
  • policyHtml, header on: the widget renders require-trusted-types-for 'script'; trusted-types orbit-widget
  • DOM nodes, header on: the widget renders require-trusted-types-for 'script'; trusted-types 'none'
