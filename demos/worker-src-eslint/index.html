Restrict the worker with ESLint

Three lint rules keep every worker inside one contract: createWorker() in worker-client.js is the only place that calls new Worker, and config.js is the only file that names a worker script. No file builds a worker from a Blob URL. The server builds worker-src from the same config.js.

  • The policy comes from config.js: the worker replies worker-src <origin>/tasks.worker.js
  • A customer who allows no worker at all: the worker is refused worker-src 'none'
