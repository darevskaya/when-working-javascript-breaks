When working JavaScript breaks

Each link opens one demo in one mode, in a new tab. The modes of a demo differ in one response header. The HTML and the JavaScript are the same.

Widget: innerHTML

  • Escaped widget breaks require-trusted-types-for 'script' Escaped values are still a string.
  • Policy widget works require-trusted-types-for 'script' The widget keeps innerHTML and uses a Trusted Types policy.
  • Policy widget breaks trusted-types shop-policy The customer allows only its own policy name.

Embedded frame: iframe sandbox

These pages send no policy. The shop puts a different sandbox attribute on the Orbit ID iframe. The login redirects the whole page.

  • Works No sandbox.
  • Login blocked allow-scripts allow-same-origin
  • Works The same, plus allow-top-navigation-by-user-activation

Order summary: eval

  • Works script-src 'self' 'unsafe-eval'
  • Blocked script-src 'self' The templates and data are our own. No user input reaches eval.

Fractal: Blob worker

  • Works worker-src 'self' blob:
  • Blocked worker-src 'self'
  • Module worker works worker-src 'self'

Popup login: COOP

  • Works Neither page sends COOP.
  • Breaks The app page sends Cross-Origin-Opener-Policy: same-origin
  • Breaks The provider sends Cross-Origin-Opener-Policy: same-origin

Popup login: BroadcastChannel

The same modes. The login returns through a callback page on the app origin, not through window.opener.

  • Works Neither page sends COOP.
  • Works The app page sends Cross-Origin-Opener-Policy: same-origin
  • Works The provider sends Cross-Origin-Opener-Policy: same-origin
